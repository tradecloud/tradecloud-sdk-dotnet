# Add User

This example updates the user roles

## Prerequisites

Super powers

## Configure

In the source code:
- amend authenticationUrl
- copy `.env.template` to `.env` and fill in `TRADECLOUD_USERNAME` and `TRADECLOUD_PASSWORD`
- add <userId> in updateUserRolesUrl
- amend user fields

## Run

```
➜  AddUser git:(master) ✗ dotnet run

```
